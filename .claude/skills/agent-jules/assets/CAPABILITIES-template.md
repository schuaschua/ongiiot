# Capabilities

## Built-in

| Code | Name | Description | Source |
|------|------|-------------|--------|
| [AQ] | answer-questionnaire | Draft cited answers for a governance questionnaire into its review file and list the open questions per lead | `references/answer-questionnaire.md` |
| [CL] | coach-lead | Walk the Product Lead or Tech Lead through their open questions and record their decisions in the review file | `references/coach-lead.md` |
| [RC] | reply-comments | Draft replies to reviewer comments in a questionnaire and apply approved ones on request | `references/reply-comments.md` |
| [CW] | comment-watch | Pulse task: find new reviewer comments in the governance folder and draft replies, never applying | `references/comment-watch.md` |
| [DR] | drift-check | Flag approved or applied answers that no longer match the current BMad artifacts | `references/drift-check.md` |
| [AL] | answer-library | Record approved answers per project with approver role and date, and retrieve them as reference only | `references/answer-library.md` |
